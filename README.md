### How It Is Built

This web page is built using only **HTML, JavaScript, and CSS**. No framework has been used because the sole purpose of this site is to publicize my portfolio.
It is developed with good labeling practices:
- *JS code structure*
- *A good use of CSS*
  - variables
  - selectors,
  - media queries,
  - comments
  - low specificity
  - and more...
